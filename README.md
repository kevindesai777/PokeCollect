This is a Kotlin Multiplatform project targeting Android, iOS.

* [/iosApp](./iosApp/iosApp) contains an iOS application. Even if you’re sharing your UI with Compose Multiplatform,
  you need this entry point for your iOS app. This is also where you should add SwiftUI code for your project.

* [/shared](./shared/src) is for code that will be shared across your Compose Multiplatform applications.
  It contains several subfolders:
  - [commonMain](./shared/src/commonMain/kotlin) is for code that’s common for all targets.
  - Other folders are for Kotlin code that will be compiled for only the platform indicated in the folder name.
    For example, if you want to use Apple’s CoreCrypto for the iOS part of your Kotlin app,
    the [iosMain](./shared/src/iosMain/kotlin) folder would be the right place for such calls.
    Similarly, if you want to edit the Desktop (JVM) specific part, the [jvmMain](./shared/src/jvmMain/kotlin)
    folder is the appropriate location.

### Running the apps

Use the run configurations provided by the run widget in your IDE's toolbar. You can also use these commands and options:

- Android app: `./gradlew :androidApp:assembleDebug`
- iOS app: open the [/iosApp](./iosApp) directory in Xcode and run it from there.

### Data

Species data (names, National Dex numbers, generations, types) is generated by
[`scripts/build_dataset.py`](scripts/build_dataset.py) from [PokéAPI](https://github.com/PokeAPI/pokeapi)
(BSD-3-Clause), pinned to a single commit, and bundled with the app.

No artwork is included in this repository. To show sprites in your own build, run
`python3 scripts/fetch_sprites.py` once before building; it downloads the classic sprites from
[PokeAPI/sprites](https://github.com/PokeAPI/sprites) into a gitignored folder. Without it the
app shows dex-number placeholders.

### On-device model (Android)

The Ask screen runs Gemma 3 1B locally through [LiteRT-LM](https://github.com/google-ai-edge/LiteRT-LM).
The model is not included in this repository. Download `gemma3-1b-it-int4.litertlm` from
[litert-community/Gemma3-1B-IT](https://huggingface.co/litert-community/Gemma3-1B-IT) (requires
accepting the Gemma licence), then push it to your device:

```bash
adb push gemma3-1b-it-int4.litertlm /data/local/tmp/llm/
```
